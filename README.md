# NLP Spam Detection

Text classification project comparing multiple ML approaches for spam detection (SVM, Naive Bayes, Logistic Regression, Random Forest, Neural Network).

## Project Structure

```
src/                - Source code
data/               - Sample datasets
tests/              - Unit tests
```

## Methods

- TF-IDF Vectorization
- Count Vectorization
- Word Embeddings (GloVe)
- Naive Bayes
- Logistic Regression
- SVM
- Random Forest
- LSTM Neural Network

## Dataset

Uses SMS Spam Collection dataset and synthetic spam/ham generation for testing.
